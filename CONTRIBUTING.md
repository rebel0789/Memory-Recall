# Contributing

Start with `ASSIGN_TO_AGENT.md`, run `npm run ci`, and select one task from `planning/backlog.json`. Keep pull requests small and include behavior, security, data, testing, and rollback notes.

By contributing, you certify the Developer Certificate of Origin in `DCO.md`. Use `git commit -s`.

Major contracts require an RFC. Architecture changes require an ADR. External dependencies and adapters require pin, license, supply-chain, trust-boundary, and conformance review.
