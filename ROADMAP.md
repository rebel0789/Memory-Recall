# Roadmap

## 0.2 — Native reliability foundation — current kit

- provider-neutral v1 contracts and compatibility fixtures;
- native SQLite/FTS5 memory baseline;
- content-addressed artifact baseline;
- cancellable embedded runtime;
- deterministic and explicit Ollama local model providers;
- portable Agent Packs;
- replay plans, run comparison, and learning proposals;
- external adapter contract fixtures.

## 0.3 — Canonical local data and authority

PostgreSQL repositories, migration runner, complete artifact retention/export, strict API validation, local identity, workspace isolation, deterministic authorization, and evented policy decisions.

## 0.4 — Context, evidence, and memory

Candidate-source ports, hybrid fusion, temporal/version resolution, persisted context manifests, evidence snapshots, citation graph, complete versioned memory service, and feedback without causal overclaiming.

## 0.5 — Durable runtime and workbench

Crash-resumable workflow adapter, bounded grants and sandbox execution, production web shell, Run and Context Inspectors, Memory/Evidence/Approval views, and privacy-safe OpenTelemetry.

## 0.6 — Creator and builder packs

File/RSS ingestion, creator-relative performance, pattern and saturation detection, outcome capture, read-side research adapters, coding-agent collaboration, repository graphs, and design workflows.

## 1.0 — Stable open reliability platform

Shadow evaluation laboratory, signed Agent Pack and skill distribution, adapter certification, backup/restore, upgrades and rollback, security audit, compatibility matrix, reproducible signed releases, and neutral governance.

The issue-sized dependency graph lives in `planning/backlog.json` and is explained in `docs/implementation/BUILD_ORDER.md`.
