# Release Readiness

## Purpose

Verify a reproducible and recoverable release without publishing.

## Procedure

1. Start from clean checkout.
2. Run bootstrap, CI, demo, migration rehearsal, backup/restore, and scans.
3. Verify status, changelog, licenses, SBOM, provenance, signing, and rollback.
4. Do not publish from this skill.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
