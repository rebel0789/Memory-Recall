# Ui Review

## Purpose

Review product UI against DESIGN.md and accessibility criteria.

## Procedure

1. Read DESIGN.md and relevant screen/component specs.
2. Review hierarchy, states, deep links, trust and consequences.
3. Run keyboard, mobile, zoom, dark/light, and reduced-motion checks.
4. Report file:location findings by severity.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
