# Source Verification

## Purpose

Verify material claims against available evidence.

## Procedure

1. List each material claim.
2. Resolve cited evidence IDs and source metadata.
3. Check time, authority, conflict, and exact support.
4. Mark supported, weak, conflicting, stale, or unsupported.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
