# Database Migration

## Purpose

Design and verify ordered, checksummed database migrations.

## Procedure

1. Define forward schema, compatibility window, and recovery.
2. Add immutable numbered migration and checksum.
3. Test clean, repeated, interrupted, and tampered cases.
4. Document backup, rollback or forward compensation.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
