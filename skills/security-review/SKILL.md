# Security Review

## Purpose

Review trust boundaries, capabilities, and data exposure.

## Procedure

1. Map assets, actors, boundaries, capabilities, and data classes.
2. Review validation, scope, secrets, egress, sandbox, approval, idempotency, and logs.
3. Add adversarial tests and stop on critical uncertainty.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
