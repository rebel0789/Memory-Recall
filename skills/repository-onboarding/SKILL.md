# Repository Onboarding

## Purpose

Orient an agent without loading the entire repository.

## Procedure

1. Run bootstrap, doctor, status, and CI.
2. Read assignment, root instructions, project status, product, design, and docs index.
3. Print the next task bundle.
4. Report environment and blockers; do not implement product scope.

## Completion

Return evidence, files changed when applicable, exact checks, risks, limitations, rollback, and safest next step. The skill never grants a tool or broadens policy.
