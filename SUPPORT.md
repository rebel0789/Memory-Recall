# Support

Memory Recall is local-first open-source software. Use GitHub Discussions for
design questions and GitHub Issues for reproducible defects in
<https://github.com/rebel0789/Memory-Recall>. Use private GitHub Security
Advisories for vulnerabilities:
<https://github.com/rebel0789/Memory-Recall/security/advisories/new>.

Community support is best effort. No service-level guarantee is promised for the
community edition.
