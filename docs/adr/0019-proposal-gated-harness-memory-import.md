# Proposal-Gated Harness Memory Import

OAF will not automatically convert harness transcripts or imported context into active memory. Codex, Claude Code, Cursor, and other harness sources may be inspected only when the user chooses them, and any extracted durable knowledge enters OAF as reviewable memory proposals until accepted, rejected, superseded, expired, or forgotten by OAF lifecycle rules. This keeps useful cross-harness memory without copying the unsafe pattern of hidden transcript capture or automatic cloud memory activation.
