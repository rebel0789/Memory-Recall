## Ponytail

The OAF agent-plugin setup shape was informed by Dietrich Gebert's `ponytail`
project, especially its small per-agent plugin manifest model and native agent
install flow. OAF reimplements the idea for OAF's governed local MCP server and
does not copy Ponytail source.
