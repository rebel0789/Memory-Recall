# Accessibility Acceptance Criteria

Target WCAG 2.2 AA.

- Semantic controls and accessible names.
- Visible focus with sufficient contrast.
- Logical tab and reading order.
- 44 × 44 CSS pixel primary targets where practical.
- No keyboard trap; Escape closes topmost dismissible surface.
- Error text connected to its field.
- Run state announced with a polite live region.
- Reduced motion honored.
- Status understandable without color.
- Graphs have outline or table equivalents.
- Charts have summaries and accessible data.

Test keyboard only, screen-reader smoke, 200% zoom, 320 px and 1440 px widths, light/dark, reduced motion, high contrast, and all primary states.
