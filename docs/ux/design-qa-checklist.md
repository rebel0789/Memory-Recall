# Design QA Checklist

## Before review

- Uses tokens, not one-off colors or spacing.
- Stable URL survives reload and back/forward.
- Empty, loading, waiting, success, warning, denied, and failure states exist.
- Local/network/external-write state is visible.
- Evidence and uncertainty are adjacent to claims.
- Dangerous actions show exact consequence and are not default focused.

## Manual review

- Keyboard-only path.
- 320 px, 768 px, and 1440 px widths.
- 200% zoom.
- Light and dark modes.
- Reduced motion.
- Slow and failed network simulation for explicit network adapters.
- Long IDs, long source text, and localized dates.
