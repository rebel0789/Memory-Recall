# GitHub Repository Setup

1. Create the repository and set default branch to `main`.
2. Replace `OWNER` placeholders in citation, issue configuration, and CODEOWNERS.
3. Enable private vulnerability reporting, secret scanning where available, Dependabot, and CodeQL.
4. Require pull requests, CI, review, resolved conversations, and signed commits or vigilant mode according to maintainer policy.
5. Add labels for area, risk, status, task ID, adapter, RFC, and breaking change.
6. Enable Discussions for architecture questions.
7. Protect release environments and signing credentials.
8. Do not enable an automated publish workflow before OAF-030.
