# Community Model

## Contributions

Use public issues, small pull requests, RFCs for contracts, ADRs for accepted architecture, DCO sign-off, automated checks, and transparent review.

## Healthy ecosystem

- stable adapter contracts and conformance suites;
- public compatibility matrix;
- reproducible examples;
- clear experimental versus supported status;
- documented deprecation windows;
- no paywall around core portability or safety behavior;
- neutral governance path before 1.0.

## Maintainer responsibility

Popularity does not replace review. Maintain realistic status, avoid hype claims, disclose commercial conflicts, protect reporter privacy, and preserve user export and local operation.
