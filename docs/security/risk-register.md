# Initial Risk Register

## R1 — Scope overwhelms delivery

Likelihood high; impact high. Mitigation: one flagship vertical, issue-sized dependency graph, one concern per pull request, explicit stop conditions.

## R2 — Context Compiler becomes an opaque ranking service

Likelihood medium; impact high. Mitigation: reason codes, score components, manifests, versioning, deterministic tie-breaking, and regression datasets.

## R3 — Third-party adapter compromise

Likelihood medium; impact high. Mitigation: disabled defaults, pins, checksums, isolation, narrow contracts, conformance and adversarial tests.

## R4 — Local-first becomes silent cloud fallback

Likelihood medium; impact critical. Mitigation: explicit model modes, residency display, no fallback, network policy, and events.

## R5 — Memory poisoning

Likelihood high; impact high. Mitigation: proposal gate, provenance, confirmation, verification, conflict handling, supersession, expiry.

## R6 — Retry repeats public action

Likelihood medium; impact critical. Mitigation: durable coordination, approval binding, idempotency, reconciliation, and no publisher until gates pass.

## R7 — Project status overclaims implementation

Likelihood high; impact medium. Mitigation: machine-readable status, repository check, bootstrap report, and wording rules.

## R8 — Licensing conflict contaminates permissive core

Likelihood medium; impact high. Mitigation: service boundaries, no vendoring, exact-commit review, notices, and maintainer approval.
