# Release Checklist

- [ ] Version, changelog, status, roadmap, and docs agree.
- [ ] Clean checkout passes bootstrap, doctor, CI, demo, and build.
- [ ] Repository manifest and source archive checksums generated.
- [ ] Dependencies, containers, adapters, and model files pinned.
- [ ] SBOM and build provenance generated.
- [ ] License and notice review complete.
- [ ] Secret and vulnerability scans pass.
- [ ] Migrations rehearsed; backup and restore pass.
- [ ] Security, accessibility, privacy, and operations reviews complete.
- [ ] External-write defaults remain off.
- [ ] Tag and artifacts signed.
- [ ] Rollback and support ownership confirmed.
- [ ] Placeholder owner URLs and contacts replaced.
