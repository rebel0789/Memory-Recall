# Release Checklist

OAF-030 generates the current release-candidate evidence under `docs/release/`.
This checklist remains the operator-facing gate; final merge, signing, and
product release publication still require explicit maintainer approval.

- [x] Version, changelog, status, roadmap, and docs agree for the release candidate.
- [x] Clean checkout gates are defined for bootstrap, doctor, CI, demo, smoke, and handoff verification.
- [x] Repository manifest and source archive checksum procedure is documented.
- [x] Dependencies, containers, adapters, and model files are inventoried in release evidence.
- [x] SBOM and build provenance are generated by `npm run release:readiness`.
- [x] License and notice review is generated under `docs/release/`.
- [x] Secret and vulnerability scans are part of `npm run check`.
- [x] Migrations rehearsed; `npm run ops:smoke` passes; database dump/restore
      is rehearsed for any PostgreSQL deployment profile.
- [x] Security, accessibility, privacy, and operations reviews are represented in release evidence.
- [x] External-write defaults remain off.
- [ ] Tag and artifacts signed in a protected maintainer environment.
- [x] Rollback and support ownership confirmed.
- [x] Owner URLs and contacts use repository-specific GitHub ownership.
- [ ] Final product merge and 1.0 release publication approved by a maintainer.
