# Builder Workspace

The Builder Workspace is the later developer-facing vertical. It coordinates coding agents without turning collaboration chat into the canonical workflow engine.

## Core capabilities

- repository map and impact analysis;
- role-specific agents and explicit handoffs;
- durable tasks, obligations, and approvals;
- isolated terminal and file capabilities;
- code, tests, artifacts, and review evidence;
- context manifests for every model-assisted change;
- architecture, security, accessibility, and release review skills.

## Adapter roles

- CCCC: collaboration and obligations, not workflow authority.
- Graphify or Understand Anything: derived repository graphs.
- Open Design: optional design workspace and artifact generation.
- Oracle: optional cross-model advisory panel, never an authority.
- ECC: reviewed procedures only; never bulk-load an entire prompt library.

Git and passing tests remain authoritative for repository state.
